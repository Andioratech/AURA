## Delivered intermediate component

The first coupled implementation is now present in `src/aura/fields/hasegawa.py`. It combines the scaled Hasegawa piston source factors with the stationary sound-hard sphere branch at every order, including `n=1`, and returns FIELD-1.0 peak complex pressure, particle velocity and pressure gradient for caller-supplied exterior Cartesian points. It is restricted to `kr <= 40`, orders 0–512, a coaxial piston at `z=0`, and the source-series convergence domain `a <= r < d` about the stationary sphere center (`d=a+H`). Points on/behind the piston-baffle plane, inside the sphere, or at/beyond `r=d` are rejected. A conservative local workspace gate executes before special-function/modal arrays; it is not yet integrated with NUM-02's run-level preflight or runtime calibration. The caller supplies piston face velocity (the frozen 15 µm displacement must be converted using the declared phasor convention) and explicit order; this function never selects an order or labels a result converged.

Thirteen focused checks now cover an unscaled modal calculation at one off-axis point inside `a<=r<d`; zero normal velocity at the front/rear poles and a 60° off-axis point; plane-wave/sphere reference agreement at three common points including stationary `n=1`; order diagnostics; and pre-allocation rejection for insufficient workspace and `r>=d`. At the 0.1 mm gap poles, order 280→300 pressure changes are `2.27e-13` (front) and `1.59e-11` (rear); these are not full-surface convergence evidence or production tolerances. A separate 37-point surface order diagnostic at that gap records maximum relative changes through orders 240–500 in the [coupled-kernel review](../reviews/NUM-03-coupled-kernel-review.md), with its ignored JSON output checksum recorded there. A first Rayleigh projection probe at this gap shows nonmonotonic surface-quadrature sensitivity and is preserved as inconclusive in the [kernel review](../reviews/NUM-03-coupled-kernel-review.md), including local script/output hashes. The follow-on priority is to control both surface and disk quadrature before treating this as an independent reference.
