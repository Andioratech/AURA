### Candidate independent-reference route: axisymmetric BEM

The fallback candidate is an axisymmetric boundary-element solve using a half-space Green function for the rigid baffle, so the unbounded baffle plane need not be meshed. The governing case would be the homogeneous, lossless, harmonic-air half-space; prescribed normal piston-face velocity on the circular aperture; zero normal velocity on the stationary sphere; and outgoing radiation. A uniqueness-enforcing exterior formulation must be selected and derived for this Neumann problem. The half-space Green-function BEM has primary method precedent for radiation/scattering near an infinite plane, but that precedent does not establish this candidate's equations or accuracy ([Li, Wu & Seybert, DOI 10.1006/jsvi.1994.1112](https://doi.org/10.1006/jsvi.1994.1112)).

The planned solver interface would accept the frozen `f`, `c`, `rho`, peak piston displacement and phasor convention, piston radius, sphere radius, gap, requested field coordinates, numerical precision, panel/quadrature refinements and resource caps. It would return complex pressure, Cartesian particle velocity and pressure gradient with units and exact configuration metadata. It would not calculate radiation force, particle acceleration or trajectories.

The verification sequence must be frozen before any BEM run: (1) piston-only field against an independently evaluated Rayleigh-disk integral and axial/far-field limits; (2) rigid-sphere scattering under an incident plane wave against the exact partial-wave solution; (3) coupled piston/sphere fields at 0.1 mm, one interior gap and the 29.9 mm outer sample against the Hasegawa series, carrying each method's uncertainty separately; and (4) at least three comparable mesh/panel levels with separate studies for singular/near-singular quadrature, linear-solver residual, arithmetic precision and field-point evaluation. For each observable (complex pressure, velocity and gradient), report absolute error and refinement differences without phase fitting. Cross-method agreement is a discrepancy check, not a bound unless both uncertainty estimates are justified.

Before implementation or execution, derive a conservative resource estimate for the exact geometry and sample vectors, record a wall-time/memory/output cap, and specify a stop rule based on the independently estimated uncertainty and the eventual approved field-use requirement. The current record supports no numerical tolerance or cap for this solver. This protocol is preparatory only: no BEM dependency, core, mesh, field calculation or P4 claim is started. The next boundary is the requested owner explanation before constructing the simulation core, including its equations/components, inputs, outputs, verification cases, resource gates and limits.


For each order `n`, let `epsilon_n` bound the source-factor integration error in exactly the dimensionless normalization consumed by the evaluator, let `T_n(r)=j_n(kr)-[j_n'(ka)/h_n^(1)'(ka)]h_n^(1)(kr)` be the stationary sound-hard radial response, and let `P_n(mu)` be the Legendre polynomial. A no-cancellation propagation at a fixed sample can use the absolute modal sums

`B_phi = sum_n |U|(2n+1) epsilon_n |T_n(r) P_n(mu)| / k`,

`B_r = sum_n |U|(2n+1) epsilon_n |T_n'(r) P_n(mu)|`, and

`B_theta = sum_n |U|(2n+1) epsilon_n |T_n(r) sqrt(1-mu^2) P_n'(mu)| / (k r)`.

The corresponding observable bounds are `B_p = rho omega B_phi`, `B_velocity = sqrt(B_r^2+B_theta^2)`, and `B_gradient = rho omega sqrt(B_r^2+B_theta^2)`, using the project convention `u=-grad(phi)` and `p=-i rho omega phi`. This is a candidate triangle-inequality construction, not a completed certificate. Convert each area-form remainder into the dimensionless source-factor normalization with the exact Eq. 2 prefactor `k^2`; the mode-0 closed-form identity above is the known-answer check for this mapping. Every retained order needs a valid `epsilon_n`; the special-function/scattering factors need bounded evaluation; and the sample geometry and units must match the frozen contract. Existing certificates do not provide this coverage for all orders 0–512, so do not report a partial sum as total uncertainty. Coordinate perturbation requires a separate spatial-sensitivity bound and is not covered by these expressions.
