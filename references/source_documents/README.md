# Source Documents

This directory preserves the original Spanish-language PDFs supplied as the source baseline for AURA. The files are retained unchanged for provenance and auditability. They are reference inputs, not current controlled specifications; use the English D00-D09 documents for maintained requirements and scientific contracts.

| Archived file | Source role |
|---|---|
| source-baseline-document-v1.0.pdf | Combined baseline containing the document register, D01-D09, and G01-G05 material |
| source-system-architecture-proposal-v0.1.pdf | Earlier architecture proposal |
| source-mclf-proposal-v0.1.pdf | Earlier MCLF proposal |

Source files were moved from the repository root and renamed descriptively. PDF contents were not edited. SHA-256 checksums are recorded in the adjacent SHA256SUMS file; compute new checksums after any intentional archival conversion.
